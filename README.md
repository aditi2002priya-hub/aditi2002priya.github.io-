🌐 Personal Portfolio Website

A responsive personal portfolio website showcasing my AWS Cloud skills, projects, education, and professional profile, deployed using AWS Cloud services.

✨ Features

- Home and About Me sections
- AWS & Cloud Computing skills showcase
- Projects section with project details
- Download Resume button
- LinkedIn and GitHub profile links
- Email contact option
- Fully responsive Desktop and Mobile design
- Professional navy blue and orange theme
- Clean and user-friendly interface
- Cloud-based deployment using AWS services

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Amazon EC2
- Amazon S3
- Apache Web Server

☁️ AWS Deployment

Deployed on AWS EC2 using Apache, with Amazon S3 for project assets and static files.
